## Project Note

This project was completed as a group project for a Data Science course in Summer 2025.

The project explores the relationship between demographic factors, political campaign contributions, and election outcomes. Using data from the U.S. Census Bureau and the Federal Election Commission, we cleaned and combined multiple datasets, performed exploratory data analysis, created visualizations, and tested whether machine learning models could identify patterns related to campaign funding and election results.

**Group Members:** Tyshon Brown, David Li, Zile Liu, and Samuel Opoku-Agyemang

**Original Group Repository:** https://github.com/9t8/cmsc320_project

### Data Sources

This project used publicly available government datasets, including:

* U.S. Census Bureau population estimates and decennial census data
* Federal Election Commission campaign finance data

These datasets were selected because they provide large-scale demographic and campaign finance information, allowing us to analyze how factors such as age, income, population, and location may relate to political contributions and election outcomes.
